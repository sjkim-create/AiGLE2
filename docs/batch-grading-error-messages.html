일괄 채점 오류 메시지 대조표

통합 구조(1단계만 입력 방식별, 데이터 매핑부터 공통)의 크래들·스캔 화면에 실제로 나오는 문구를 단계별로 나란히 놓았습니다. 청록 행은 기존 채점 관리 모달과 동작·문구가 달라진 곳, 보라 행은 현장에서 날 수 있는데 아직 문구가 없는 곳이며 제안 문구를 붙였습니다.

차단 다음 단계로 못 넘어감 주의 진행은 되지만 누락·제외가 생김 안내 알려 주기만 함 기존과 다름 채점 관리 모달과 달라짐 미구현 문구가 아직 없음

정해야 할 것 4건

  1. 크래들 · 읽지 않은 펜이 있으면 채점을 막을지 — 통합 시안은 막고 「아직 읽지 않은 펜 n자루가 있습니다 — [↻ 다시 매칭]」을 띄웁니다. 기존 모달은 막지 않고 그 펜만 뺐습니다. 채택하면 SCR-07 채점 시작 조건을 고칩니다.
  2. 크래들 · 중복 해소 방식 — 통합 시안은 「이 펜이 ○○의 답안입니다」로 한쪽을 고르면 다른 펜이 미분류로 갑니다. 기존은 잘못 붙은 펜을 다른 학생에게 직접 매칭하는 방법만 있었습니다. 차단 문구도 달라졌습니다.
  3. 스캔 · 다른 반 답안지 — 답안지 코드가 과제·장 단위라 같은 과제의 다른 반 답안지를 가려내지 못합니다. 크래들은 북코드로 「그룹 불일치」를 잡습니다.
  4. 크래들 · 이미 답안이 있는 학생 — 스캔은 교체 확인창 2종과 되돌리기가 있지만, 크래들은 확인 없이 덮어씁니다.
