# aigle-v2 (손에 잡히는 문해력 · 선생님용) 역기획서

> 조사일: 2026-10-27 · 대상: https://aigle-v2.vercel.app/teacher/* (데모 선생님 계정)
> 방법: 공개 화면 관찰 + 페이지 구조(DOM) · 스크립트 · 네트워크 요청 관찰. 화면 상태를 바꾸는 동작(수업 종료 · 삭제 · 학급 만들기 등)은 누르지 않았다
> 근거 표기: **[확인]** 화면 · 요청으로 확인 / **[추정]** 흔적으로 추정
> 목적: 우리 「정답형 과제」 화면(문항 · 문제집)이 산만하고 고치기 불편하다는 문제를 정리하는 데 참고. 잘 만들었다는 판단은 하지 않고, **정리 방식**만 본다

---

## 1. 한 줄 정의

차시별 종이 교재(학습지)를 스마트펜 · 태블릿으로 수업하고, 학생 진행을 실시간으로 보며, 수업 기록 · 누적 성장을 보는 교사용 수업 도구. 교재는 미리 만들어진 콘텐츠이고 교사가 문항을 만들거나 고치는 기능은 없다 **[확인: 편집 버튼 없음]**

## 2. 정보 구조 (IA) **[확인]**

```
상단 메뉴(가로 탭, 사이드바 없음) — 교사 작업 순서대로
  나의 학급   /teacher/classes   준비: 학급 · 학생 · 펜
  수업 자료   /teacher/materials 무엇으로: 차시별 교재
  수업하기    /teacher/live      진행 중: 실시간 학생 현황  (진행 중이면 메뉴에 「● 수업 중」)
  수업 분석   /teacher/records · /teacher/growth   결과: 수업 기록 · 누적 성장
오른쪽 위: 언어 선택 · 프로필(김네오 선생님)
```

- 메뉴가 4개뿐이고 **교사의 하루 순서(준비 → 자료 → 수업 → 분석)** 로 놓였다
- 하위 메뉴가 필요한 곳(수업 분석)만 왼쪽에 작은 하위 메뉴 + 학급 선택 상자

## 3. 화면별 정리

### 3.1 수업 자료 — 차시 카드 목록 (우리 「문제집」과 같은 자리)

| 요소 | 내용 |
|---|---|
| 단위 | **차시 1개 = 카드 1장** (1차시 악어가 무서워 · 2차시 밤의 정원) |
| 왼쪽 | 실제 학습지 **쪽 미리보기 썸네일**을 가로로 나열(넘치면 가로 스크롤) — 무엇이 인쇄되는지 바로 보인다 |
| 오른쪽 위 | 제목(차시 + 제목) · 한 줄 설명(학습 목표 + 교재 쪽 범위, 예: 「받침 있는 낱말 읽고 쓰기 (홑받침 ㄱ, ㅋ), 교재 3~6쪽」) |
| 오른쪽 가운데 | **구성 요약** — 활동 묶음 4종(읽기 술술 · 이해 탄탄 · 핵심 콕콕 · 놀이 팡팡)별 활동 수를 2×2로 |
| 오른쪽 아래 | 주된 행동 **하나**: [학습지 PDF] |
| 없는 것 | 검색 · 필터 · 선택 체크 · 일괄 변경 · 편집 — 콘텐츠가 적고 교사가 고치지 않으므로 |

### 3.2 나의 학급 — 학급 카드

- 학급마다: 이름 · 「학생 30명, 최근 수업 10월 27일」 · 학급 코드 · 다음 수업(예약 없음) · 버튼 [수업하기] [학생 명단] [설정]
- 위에 공용 정보 한 줄: 「펜 번호 설정하기 · 모든 학급 공용 · 등록된 펜 10자루」 · 맨 아래 [학급 만들기]

### 3.3 수업하기 — 실시간 현황

- 머리: 학급 · 차시 · 경과 시간 · 「들어온 학생 0/30명」 · [입장 QR] · [수업 종료](빨강, 하나만 강조)
- 왼쪽: 학생 타일 격자 — 정렬(번호순 / 들어온 학생 먼저) · 밀도(3 · 4 · 5명씩) · 🔍 · 필터 아이콘
  - 타일: 번호 · 이름 · 상태 배지(나감 · 입장 전) · 지금 보는 쪽 썸네일 · 「마지막 3쪽」 · 진행률 % · 쪽별 진행 막대
- 오른쪽: 교사 조작만 모은 패널 — 「모두 같은 쪽 열기」(쪽 + 활동 이름 버튼 4개) · 「주의집중 켜기」

### 3.4 수업 분석

- 수업 기록: 표(날짜 · 시간 또는 「진행 중」 · 교재·차시 · 방식 「학습지 + 태블릿」 · **다 한 학생 n/30명 진행 막대** · [펜 기록 불러오기] · 🗑)
- 누적 성장: 학급 평균 + 학생별 선(옅게) 추이, 배경 띠로 기준 구간(안정적 70점 이상 · 성장 중 60~69 · 집중 지도 필요 60 미만), 지표 전환(성장 지수 · 읽기 시간 · 자기 교정), 「학생 상태 분포」 도넛

## 4. 기술 관찰 **[확인]**

| 항목 | 관찰 |
|---|---|
| 프레임워크 · 배포 | Next.js(Turbopack 빌드 조각 `_next/static/chunks/turbopack-…`) · Vercel |
| 교재 자산 | 쪽 이미지 `/lit/munhae/01/p3.png` …, 인쇄본 `/lit/munhae/01/print.pdf` — 차시마다 쪽 이미지와 PDF를 미리 만들어 둠 |
| 데이터 | `/api/roster`(학생 명단) · `/api/sync?since=n`(바뀐 것만 이어 받기) · `/api/live?class=c1`(수업 중 현황, 몇 초 간격으로 반복 요청) · `/api/version` |
| 글꼴 | Pretendard |
| 로딩 | 화면 진입 시 회색 막대(스켈레톤) 먼저 → 내용 |

## 5. 한계 — 이 사이트로 알 수 없는 것

- **문항을 만들고 고치는 화면이 없다** → 우리가 불편하다는 「수정」은 이 사이트로 참고할 수 없다. 수정 화면은 다른 서비스를 참고해야 한다(§7)
- 데모라 차시가 2개뿐이다 → 자료가 수백 개일 때(우리 문제 은행) 목록을 어떻게 다루는지는 보이지 않는다
- 실제 교사 반응 · 사용 지표는 없다 — 「정리가 잘됐다」는 화면 구성 관찰일 뿐이다 **(사용자 근거 없음)**

## 6. 정리 원칙 — 우리 화면에 빌려 올 것

| # | 원칙 | aigle-v2에서 | 우리 정답형 과제에 |
|---|---|---|---|
| 1 | **한 화면 = 한 목적, 주된 버튼 하나** | 수업 자료 카드의 [학습지 PDF] 하나 | 문제집 카드는 [시험지 출력] 하나만 드러내고 나머지는 ⋯ 메뉴 |
| 2 | **무엇이 인쇄되는지 그림으로** | 쪽 썸네일 가로 나열 | 문제집 카드 왼쪽에 시험지 쪽 미리보기 |
| 3 | **구성은 숫자 요약으로** | 활동 묶음별 개수 2×2 | 유형별 문항 수(선다형 12 · 단답형 6 …) |
| 4 | **한 줄 설명에 범위까지** | 학습 목표 + 교재 쪽 | 교과 · 학년 · 단원 + 출처 자료 쪽 |
| 5 | **필터는 아이콘 뒤로** | 수업하기 🔍 · 필터 아이콘, 기본 화면엔 정렬 2개만 | 기본은 검색 1칸 + 유형 칩, 교과 · 수준 · 단원 · 학교급 · 상태 · 자료는 [필터 ▾] 안으로 |
| 6 | **상태는 배지 · 막대로** | 「입장 전 · 나감」, 「다 한 학생 n/30」 | 문항 상태(확인 필요 n · 완료) · 문제집 진행(배포 · 채점) |
| 7 | **교사 조작은 한쪽에 모으기** | 수업하기 오른쪽 패널 | 고른 문항 일괄 변경은 선택할 때만 나타나는 한 줄 바에 |

## 7. 「수정 불편」은 다른 서비스를 참고

| 참고 | 볼 점 |
|---|---|
| Google Forms | 질문 카드를 누르면 **그 자리에서 펼쳐져 편집**(창이 뜨지 않음), 유형은 카드 오른쪽 위 선택 상자 하나 |
| Quizizz · Kahoot 퀴즈 편집 | **왼쪽 문항 목록(번호 · 유형 아이콘 · 첫 줄) + 오른쪽 편집 화면**이 늘 같이 보임 — 다음 문항으로 넘어가며 연달아 고치기 좋다 |
| Notion 데이터베이스 | 표에서 칸을 눌러 바로 고치기 · 필터는 [필터] 버튼 뒤에 칩으로 쌓임 |
