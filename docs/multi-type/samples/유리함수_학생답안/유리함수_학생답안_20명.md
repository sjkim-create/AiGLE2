# 유리함수 과제 — 학생 답안 예시 (20명 × 3문항)

> 시연 · AI 채점 테스트용 **가상 답안**(이름 가상). 3번 학생(박지호)의 답안만 제공된 실제 답안을 옮겼다.
> 예상 점수는 `assignment-유리함수.json`의 채점 기준표 기준. **⚠ 경계** = 기준표만으로 점수를 정하기 애매해 교사 판단이 필요한 답안

## 1. 문항 · 채점 기준

**문항 1 (2점)** 유리함수의 정의를 쓰시오.  
- 예시 답안: 함수 y = f(x)에서 f(x)가 x에 대한 유리식일 때, 이 함수를 유리함수라 한다.
- 2점: 유리함수의 정의를 옳게 쓴 경우
- 1점: 유리함수를 분수함수라고 정의한 경우 / y=(ax+b)/(cx+d) 형식으로 정의한 경우
- 0점: 정의를 쓰지 못한 경우

**문항 2 (3점)** 실생활 속에서 다항함수가 아닌 유리함수의 예를 찾아 설명하고 식으로 나타내시오.  
- 예시 답안: 50g의 물에 xg의 소금을 넣었을 때 소금물의 농도를 y%라 하자. 이때의 다항함수가 아닌 유리함수의 식은 y = 100x/(x+50)이다.
- 3점: 예를 설명하고 식으로 올바르게 작성한 경우
- 1점: 예를 설명했으나 식으로 표현하지 못한 경우 / 식은 세웠으나 실생활 예로 설명하지 못한 경우
- 0점: 예를 설명하지 못하고 식으로 작성하지 못한 경우

**문항 3 (5점)** 그림과 같은 유리함수의 그래프가 나타나는 함수의 식을 구하시오. (점근선 x=2, y=−1, 점 (3, 0)을 지남)  
- 예시 답안: 점근선 x=2, y=−1 → y = k/(x−2) − 1 (k≠0). 점 (3, 0)을 지나므로 0 = k/(3−2) − 1, k = 1. ∴ y = 1/(x−2) − 1
- 5점: 점근선으로 y=k/(x−2)−1을 쓰고 (3,0) 대입해 k=1, y=1/(x−2)−1을 찾은 경우
- 3점: 점근선을 이용해 y=k/(x−2)−1을 작성한 경우
- 1점: 유리함수의 식만 y=k/(x−2)−1 찾은 경우
- 0점: 식을 구하지 못한 경우

## 4. 학생별 답안

### 1. 김도윤 (1학년 3반 1번) — 수준 상 · 예상 10/10점

**문항 1** · Q1-A 교과서 정의 · 예상 2/2점
```
함수 y = f(x)에서 f(x)가 x에 대한 유리식일 때
이 함수를 유리함수라고 한다.
```

**문항 2** · Q2-B 평균 비용 · 예상 3/3점
```
<티셔츠 단체 주문>
디자인 비용 30000원은 한 번만 내고, 티셔츠는 한 장에 5000원이다.
x장을 주문할 때 한 장당 평균 가격을 y원이라 하면
y = (5000x + 30000)/x = 30000/x + 5000
많이 주문할수록 한 장당 가격이 5000원에 가까워진다.
```

**문항 3** · Q3-A 표준형 k · 예상 5/5점
```
점근선 x = 2, y = −1
y = k/(x − 2) − 1 (k ≠ 0)
(3, 0)을 지나므로 0 = k/(3 − 2) − 1
k = 1
∴ y = 1/(x − 2) − 1
```

### 2. 이서연 (1학년 3반 2번) — 수준 상 · 예상 10/10점

**문항 1** · Q1-B 다항식의 비 · 예상 2/2점
```
두 다항식 P(x), Q(x)에 대하여
y = P(x)/Q(x) (Q(x)는 0이 아닌 다항식)로 나타내어지는 함수를 유리함수라 한다.
```

**문항 2** · Q2-C 병렬 저항 · 예상 3/3점
```
<병렬 회로의 합성 저항>
2Ω 저항과 xΩ 저항을 병렬로 연결하면 합성 저항 y는
1/y = 1/2 + 1/x
y = 2x/(x + 2)
x가 아무리 커져도 y는 2Ω을 넘지 않는다.
```

**문항 3** · Q3-B 분자 미지수형 · 예상 5/5점
```
세로 점근선이 x = 2이므로 분모는 x − 2
y = (ax + b)/(x − 2)로 놓으면 가로 점근선은 y = a = −1
y = (−x + b)/(x − 2)
(3, 0) 대입: 0 = (−3 + b)/1, b = 3
∴ y = (−x + 3)/(x − 2)
```
- 메모: 표준형으로 바꾸면 y = 1/(x−2) − 1과 같은 함수. 형태가 달라도 정답으로 인정할지 기준표에 명시 필요

- 메모: 제공된 실제 학생 답안

**문항 2** · Q2-D 소금물 + 표준형 변형 · 예상 3/3점
```
<소금물의 농도>
물 100g에 소금 xg을 녹인 소금물의 농도를
y%라고 할 때
y = 100x/(100 + x) = −10000/(x + 100) + 100
```
- 메모: 제공된 실제 학생 답안

**문항 3** · Q3-C 두 미지수 + 대칭점 연립(원본 답안) · 예상 3/5점 · ⚠ 경계
```
점근선 x = 2, y = −1
→ y = b/(ax − 2) − 1
(3, 0)을 지나므로 대입
→ 0 = b/(3a − 2) − 1
1 = b/(3a − 2)
3a − 2 = b, 3a − b = 2
(2, −1)에 대해 대칭이므로 (1, −2)도 지남
→ −2 = b/(a − 2) − 1
−1 = b/(a − 2)
−a + 2 = b, 2 = a + b
연립하면
3a − b = 2
+) a + b = 2
4a = 4
a = 1, b = 1
```
- 메모: 제공된 실제 학생 답안. a, b는 맞게 구했으나 최종 식 y = 1/(x−2) − 1을 쓰지 않음. 또 b/(ax−2)의 세로 점근선은 x = 2/a라 a = 1일 때만 x = 2 — 가정에 논리 틈. 5점 / 3점 교사 판단

### 4. 최하은 (1학년 3반 4번) — 수준 상 · 예상 10/10점

**문항 1** · Q1-C 정의 + 다항함수 포함 · 예상 2/2점

f(x)가 x에 대한 유리식인 함수 y = f(x)를 유리함수라 한다.

농도 y% = (소금의 양)/(소금물의 양) × 100

```

**문항 3** · Q3-D 평행이동 · 예상 5/5점

```

## 5. 기준표 보완이 필요한 경우 (경계 답안에서 나온 것)

- **문항 2**: 실생활 예는 들었으나 **다항함수**(1차함수)인 경우 — 0점 / 1점 기준 없음 (16번)
- **문항 3**: **같은 함수의 다른 형태**(y = (−x+3)/(x−2)) 인정 여부 (2 · 14번)
- **문항 3**: **과정 없이 답만** 맞은 경우 (17번), **최종 식 미기재 · 옮겨 쓰기 부호 실수 · 「y =」 누락** 같은 표기 실수 감점 (3 · 6 · 12번)
- **문항 3**: **점근선을 잘못 읽었지만 방법은 맞은** 경우 부분 점수 (16번)
- **문항 1**: 「다항식 ÷ 다항식」처럼 유리식이라는 말을 안 쓴 정확한 설명 (6번)
